## 상표

F1, FORMULA 1, GRAND PRIX 등은 Formula One Licensing BV의 상표이고, FIA 로고는 FIA의 상표다. 이 서비스는 FIA·Formula 1과 관련 없는 교육용 프로젝트이며 로고를 사용하지 않는다. 판정 해설·사실 판정 결과에는 "FIA의 공식 판정이나 해석이 아님" 안내를 붙인다.

## 수집 로그

- `data/cache/collect_cache.json`: 경기별로 수집한 검색어, 시각, 선택된 문서 ID
- `f1_docs` 청크 메타데이터: `url`, `collected_at`, `query`
- `data/processed/wiki_coverage.csv`: 경기별 위키 문서 커버리지

## 화면의 우승 차 사진

- 출처: 위키미디어 공용(Wikimedia Commons). 위키백과 차 문서의 대표 사진 중 자유 라이선스 사진만 쓴다(MediaWiki API `pilicense=free`).
- 이용 조건: 대부분 CC BY-SA 또는 CC BY. 화면의 사진 아래에 작성자, 라이선스(링크), 원본 파일 페이지 링크를 표시한다. 작성자나 라이선스 정보가 없는 사진은 쓰지 않는다.
- 사진은 위키미디어 서버에서 바로 불러오며 프로젝트에 저장하거나 수정하지 않는다. 답변의 근거로는 쓰지 않는다.
- 사진은 그 시즌 차를 보여 줄 뿐 그 경기에서 찍은 사진이 아닐 수 있어, 화면에 그렇게 적는다.
